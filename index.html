Pattern 01

Two Pointers

Maintain converging or fast-slow pointer invariants to eliminate nested loops in sorted sequences in O(N).

LC 11, LC 15 (3Sum), LC 42 (Rain Water)
Pattern 02

Sliding Window

Expand right pointer to satisfy constraint; contract left pointer monotonically to restore validity.

LC 3, LC 76 (Min Window), LC 424
Pattern 03

Fast & Slow Pointers

Floyd's cycle detection (1x and 2x speeds) to detect loops and find cycle entry points in O(N) time and O(1) memory.

LC 141 (Cycle), LC 142 (Cycle II), LC 287
Pattern 04

Prefix Sum & Hash Map

Converts range sum queries to O(1); finds subarray sum == K even when negative values rule out sliding windows.

LC 560 (Sum == K), LC 525, LC 974
Pattern 05

Monotonic Stack / Queue

Maintains strictly ordered elements to find the Next Greater or Smaller Element in O(N) linear amortized time.

LC 739 (Daily Temp), LC 84 (Histograms), LC 85
Pattern 06

Merge Intervals

Sort by interval start time; merge overlaps when curr.start <= prev.end to resolve calendar conflicts.

LC 56 (Merge), LC 57 (Insert), LC 253 (Meeting Rooms)
Pattern 07

Binary Search on Answer

When checking feasibility is monotonic (True...True, False...False), binary search the answer domain directly.

LC 875 (Koko), LC 1011 (Ship Capacity), LC 410
Pattern 08

Top 'K' Elements (Heaps)

Maintain a bounded Min-Heap of size K to find top K elements in O(N log K) without sorting the full array.

LC 215 (Kth Largest), LC 347 (Top K Frequent), LC 373
Pattern 09

Two Heaps (Running Median)

Balance Max-Heap (lower half) and Min-Heap (upper half) to extract rolling streaming medians in O(1) time.

LC 295 (Median Stream), LC 480 (Sliding Median)
Pattern 10

BFS & Multi-Source BFS

Level-order FIFO queue exploration guaranteed to find unweighted shortest paths and simultaneous wavefronts.

LC 102 (Level Order), LC 994 (Rotting Oranges), LC 127
Pattern 11

DFS & Tree Traversals

Recursive stack propagation to evaluate tree heights, path sums, LCA, and subtree topological properties bottom-up.

2D Matrix / Grid Traversal

Treat 2D coordinates (r, c) as implicit graph nodes with 4-directional boundary checks and in-place visited bitmasks.

Engineering Invariants
Mental Models

The four laws of production backend code.

Principles distilled from debugging live systems, optimizing relational databases, and reading architectural classics.

Law 01

Idempotency is Non-Negotiable

Every POST or mutation API that modifies account balances, inventory, or orders must handle network retries safely. If the client retries an identical request ID, the response must be identical with zero secondary deductions.

Law 02

Index with Intent

Indexes are not magic sprinkles. Understand composite B+ Tree ordering (Equality first, Range second). A query that misses the leftmost prefix forces a sequential scan regardless of how many indexes you create.

Law 03

Decouple by Failure Domain

Never execute long-running I/O or SLA timers inside web request handlers. If the API worker restarts during a deployment, in-memory timers die. Asynchronous work belongs in resilient Redis/Celery queue workers.

Law 04

Test Concurrency Boundaries

Single-threaded unit tests only prove your happy path works. Production failures happen when 50 threads compete for the same row. Automated integration tests must simulate race conditions, deadlocks, and network partitions.
